How it works
  1. Install the MythicPlusTracker addon in your WoW addons folder
  2. Play M+ dungeons — the addon automatically saves run data
  3. After your session, point this importer at the SavedVariables file and click Import

Addon location: wow_addon/MythicPlusTracker/ in this project.
Copy it to: World of Warcraft/_retail_/Interface/AddOns/MythicPlusTracker/

Typical paths:
Windows: C:\Program Files\World of Warcraft\_retail_\WTF\Account\YOURACCOUNT\SavedVariables\MythicPlusTracker.lua
Mac: /Applications/World of Warcraft/_retail_/WTF/Account/YOURACCOUNT/SavedVariables/MythicPlusTracker.lua
