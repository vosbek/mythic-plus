To use Warcraft Logs integration:

  2. Copy your Client ID and Client Secret to your .env file

How it works

This fetches your recent M+ runs from Warcraft Logs and either:

  • Creates new runs if they don't exist in your tracker yet
  • Enriches existing runs (from addon import) with DPS/HPS data per player

Matching is done by dungeon + key level + timestamp, so addon-imported runs get linked to their WCL reports automatically.

What gets imported/enriched

DataNew RunsEnrichment
Dungeon, key levelYes--
Timed/depleted, durationYes--
Group compositionYes--
DPS per playerYesYes
HPS per playerYesYes
WCL report linkYesYes

Data is fetched via the Warcraft Logs API v2 (GraphQL). You must upload your combat logs to Warcraft Logs for this to work.
